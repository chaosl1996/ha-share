# HA Share

**Home Assistant 实体临时分享网关** —— 一条链接，让访客免登录查看或控制你指定的实体。

Generate temporary, password-protected share links for any Home Assistant entity — visitors need no HA account.

## 功能特性

- **多实体分享**：一条分享链接可绑定任意多个 HA 实体（灯、锁、窗帘、空调、播放器、开关、脚本、自动化等全部支持）
- **每实体独立权限**：只读 / 允许控制，各自独立配置
- **每实体独立操作次数**：一次性 / N 次 / 无限，仅成功执行控制才扣减该实体自身次数，查看与刷新不计；次数耗尽只禁用该实体控件，其余实体不受影响
- **全局有效期**：整条分享统一生效/失效时间区间
- **访问密码**：自定义或随机生成，PBKDF2 存储；密码错误次数超限自动锁定防暴力破解
- **短链 + 二维码**：32 位 UUID v4 链接防遍历，一键生成二维码 PNG 下载
- **访客页免登录**：移动端优先，自动加载全部绑定实体实时状态，定时轮询 + 手动刷新
- **原生风格控件**：按实体类型渲染 —— 灯（亮度/色温/色彩）、锁（二次确认）、窗帘（位置滑块）、空调（模式/温度/风速）、播放器（播放/音量）、风扇（百分比）、脚本/场景（执行）、自动化（开关/触发）等；未知类型自动发现可用服务渲染按钮
- **UI 自定义**：分享名称/描述、深浅主题、卡片背景/文字/强调色、页面文案、每实体自定义图标与属性展示开关
- **审计日志**：访问、密码验证、控制操作、拦截记录全程留痕，支持筛选与 CSV 导出
- **零外部依赖**：无独立服务、无数据库，复用 HA 原生管理员鉴权，数据存于 HA `.storage`

## 安装

### 方式一：HACS（推荐）

1. HACS → ⋮ → 自定义仓库
2. 仓库填 `https://github.com/chaosl1996/ha-share`，类别选 **集成 (Integration)**
3. 搜索 **HA Share** 并安装
4. 重启 Home Assistant

### 方式二：手动安装

```bash
cd <HA配置目录>/custom_components
git clone https://github.com/chaosl1996/ha-share
cp -r ha-share/custom_components/ha_share .
```

然后重启 Home Assistant。

## 快速上手

1. **设置 → 设备与服务 → 添加集成**，搜索 **HA Share** 添加（无需任何配置项）
2. 侧边栏出现 **HA Share** 面板（仅管理员可见）
3. 点击 **＋ 新建分享**：
   - 搜索并勾选要分享的实体（163+ 实体中任意多选）
   - 为每个实体设置权限（只读/控制）与操作次数
   - 设置有效期区间、访问密码（可随机生成）
   - 可自定义访客页主题与文案
4. 保存后复制 **分享链接** 或下载 **二维码** 发给访客
5. 访客打开链接 → 输入密码 → 即可查看状态 / 按权限控制

> 面板设置中的 **外网基础地址**（base_url）用于拼接分享链接。内网测试可填 `http://<内网IP>:8123`；外网分享请填你的 HTTPS 域名，并自行部署反向代理（见下方安全说明）。

## 全局设置

面板「设置」标签页可配置：

| 配置 | 说明 | 默认 |
|---|---|---|
| 外网基础地址 | 拼接分享链接的前缀 | HA external_url |
| 轮询间隔 | 访客页自动刷新间隔（秒） | 5 |
| 日志保留天数 | 审计日志保留时长 | 90 |
| 密码尝试上限 | 单条分享连续错误锁定阈值 | 5 |
| 锁定时长 | 触发锁定后的冷却时间（秒） | 300 |

## 安全机制

- 分享 ID 为 32 位 UUID v4（128 位随机），不可枚举遍历
- 访问密码 PBKDF2-SHA256（20 万次迭代）哈希存储，明文不落盘
- 连续密码错误达到上限自动锁定分享，冷却期内拒绝访问
- 管理面板与全部管理命令 `require_admin` 双层强制校验
- 访客仅能访问该分享绑定的实体，无法探测其他实体或调用任意服务
- 每次控制操作记录来源 IP、实体、动作、剩余次数，全程可审计
- 链接可随时**停用**或**删除**，立即生效

> **外网访问须知**：本集成只提供 HTTP 端点。通过公网分享请务必使用 HTTPS（自建反向代理 + TLS，或 HA 官方 Nabu Casa / Let's Encrypt 方案）。密码经 HTTPS 传输才有意义。

## 常见问题

**Q: 访客能控制我未分享的实体吗？**
不能。后端对每个控制请求校验实体是否在该分享列表内、是否有控制权限、剩余次数是否 > 0。

**Q: 次数扣减规则是什么？**
仅成功执行控制动作才扣减对应实体自己的次数（预留-回滚机制，服务调用失败自动返还）；查看、刷新、只读实体永不扣减。

**Q: 分享过期/停用后访客看到什么？**
访客页显示对应的状态页（未开始/已过期/已停用/已锁定），不暴露任何实体数据。

**Q: 升级集成后面板没更新？**
面板模块 URL 含文件版本指纹，重启 HA 后自动加载新版本；如仍显示旧界面，强制刷新浏览器（⌘⇧R）一次即可。

## 开发

仓库结构：

```
├── custom_components/ha_share/   # 集成后端 + 内置前端产物 (www/)
│   └── www/panel.js              # 管理面板构建产物（已提交）
└── frontend/                     # 管理面板源码 (Lit 3)
    ├── src/panel.js
    └── build.sh
```

管理面板基于 **Lit 3 + esbuild** 构建（HA 前端无 import map，必须打包）：

```bash
cd frontend
# 首次需准备依赖（vendor/esbuild 二进制与 lit 模块，不入库）：
#   esbuild:  https://registry.npmmirror.com/@esbuild/darwin-arm64/-/darwin-arm64-0.28.2.tgz
#   lit:      https://registry.npmmirror.com/lit/-/lit-3.3.3.tgz（及 lit-element / lit-html / @lit/reactive-element）
./build.sh    # 产物写入 custom_components/ha_share/www/panel.js
```

构建后重启 HA 即可看到新面板（模块 URL 自动换新，无需清缓存）。
